ТЕСТЫ MATHTOOL — ЛАБОРАТОРНАЯ РАБОТА 2

Запускать из каталога проекта под Python 3.12 или новее.
В PowerShell после команды код возврата показывает $LASTEXITCODE.
В активном окружении вместо python можно писать .\.venv\Scripts\python.exe.
Поля stdout/stderr ниже содержат полный текст без сокращений.
Для stdin скопировать данные в конвейер либо файл, например
"4 1 5" | python mathtool.py stats
