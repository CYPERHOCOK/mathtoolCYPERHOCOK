ТЕСТЫ ДЛЯ ПРИЛОЖЕНИЯ MATHTOOL

После каждой команды код возврата в PowerShell можно проверить командой:
$LASTEXITCODE

1. Запуск без параметров
Команда: python mathtool.py
Ожидается: справка по использованию; код возврата 0.

2. Запуск с параметром --help
Команда: python mathtool.py --help
Ожидается: справка по использованию; код возврата 0.

3. Неизвестная команда
Команда: python mathtool.py start
Ожидается: ОШИБКА: неизвестная команда; код возврата 1.

4. Неполный набор параметров
Команда: python mathtool.py solve -a 1 -b -3
Ожидается: ОШИБКА: неверный набор параметров; код возврата 1.

5. Лишний параметр
Команда: python mathtool.py solve -a 1 -b -3 -c 2 extra
Ожидается: ОШИБКА: неверный набор параметров; код возврата 1.

6. Неизвестный параметр
Команда: python mathtool.py solve -a 1 -q -3 -c 2
Ожидается: ОШИБКА: неизвестный параметр; код возврата 1.

7. Коэффициент не является целым числом
Команда: python mathtool.py solve -a abc -b 1 -c 1
Ожидается: ОШИБКА: коэффициент не является целым числом; код возврата 1.

8. Значение вне допустимого диапазона
Команда: python mathtool.py solve -a 50000 -b 1 -c 1
Ожидается: ОШИБКА: значение вне допустимого диапазона; код возврата 1.

9. Квадратное уравнение с двумя корнями
Команда: python mathtool.py solve -a 1 -b -3 -c 2
Ожидается:
Уравнение квадратное
D = 1
x1 = 2.000
x2 = 1.000
Код возврата 0.

10. Квадратное уравнение с одним корнем
Команда: python mathtool.py solve -a 1 -b -2 -c 1
Ожидается:
Уравнение квадратное
D = 0
x = 1.000
Код возврата 0.

11. Квадратное уравнение без действительных корней
Команда: python mathtool.py solve -a 1 -b 0 -c 5
Ожидается:
Уравнение квадратное
D = -20
Действительных корней нет
Код возврата 0.

12. Линейное уравнение
Команда: python mathtool.py solve -a 0 -b 2 -c -4
Ожидается:
Уравнение линейное
x = 2.000
Код возврата 0.

13. A = 0 и B = 0, C = 0
Команда: python mathtool.py solve -a 0 -b 0 -c 0
Ожидается: ОШИБКА: это не уравнение, неизвестное отсутствует; код возврата 1.

14. A = 0 и B = 0, C не равен нулю
Команда: python mathtool.py solve -a 0 -b 0 -c 7
Ожидается: ОШИБКА: это не уравнение, неизвестное отсутствует; код возврата 1.

15. Ввод коэффициентов с клавиатуры
Команда: python mathtool.py solve
Ввести по очереди: 1, -3, 2.
Ожидается такой же результат, как в тесте 9; код возврата 0.

16. Ошибка при вводе с клавиатуры
Команда: python mathtool.py solve
Ввести A: abc
Ожидается: ОШИБКА: коэффициент не является целым числом; код возврата 1.
