# Лабораторная работа № 1 «Решение уравнения»

Консольное приложение решает уравнения вида `A*x^2 + B*x + C = 0`.

## Состав проекта

- `main.py` — учебный файл из первой части лабораторной работы;
- `mathtool.py` — основная программа;
- `tests.txt` — набор тестов;
- `.gitignore` — список файлов, которые не следует добавлять в репозиторий.

## Требования

- Python 3.12 или новее;
- дополнительные библиотеки устанавливать не требуется.

## Запуск в PyCharm

1. Распаковать архив.
2. В PyCharm выбрать **Open** и открыть папку `mathtool`.
3. Убедиться, что для проекта выбран интерпретатор Python 3.12 или новее.
4. Открыть встроенный терминал PyCharm.
5. Выполнить одну из команд:

```text
python mathtool.py
python mathtool.py --help
python mathtool.py solve
python mathtool.py solve -a 1 -b -3 -c 2
```

Если команда `python` не работает в Windows, попробовать `py`:

```text
py mathtool.py solve -a 1 -b -3 -c 2
```

## Проверка кода возврата

После запуска в PowerShell:

```text
$LASTEXITCODE
```

При успешной работе программа возвращает `0`, при ошибке — `1`.

## Публикация работы

Для сдачи необходимо создать удалённый репозиторий на GitHub, GitLab или
GitVerse, сделать несколько последовательных коммитов и отправить преподавателю
ссылку на репозиторий. Один итоговый коммит не показывает историю выполнения
работы, поэтому файлы лучше добавлять поэтапно.

В PyCharm можно включить Git через **VCS → Enable Version Control Integration → Git**.
Если Git не найден, его потребуется установить отдельно. После этого файлы можно
добавить несколькими коммитами, например:

1. `.gitignore` и `README.md` — `Создан репозиторий и добавлено описание`;
2. `main.py` — `Добавлена первая программа`;
3. `mathtool.py` — `Добавлено решение уравнений`;
4. `tests.txt` — `Добавлены тесты приложения`.

Затем нужно создать пустой репозиторий `mathtool` на GitHub, GitLab или GitVerse,
добавить его как удалённый репозиторий и выполнить Push.
