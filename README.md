# Mathtool — лабораторные работы 1 и 2

Гонжаленко Демид. Разработка консольных приложений.

Приложение решает уравнения, вычисляет показатели числовой последовательности,
суммирует ряды и приближённо вычисляет интегралы методом левых прямоугольников.
Реализованы все команды основного задания лабораторной работы 2.

## Запуск в PowerShell

Требуется Python 3.12 или новее, дополнительные библиотеки не нужны.
Открыть терминал и перейти в каталог проекта:

```powershell
cd "$env:USERPROFILE\Desktop\Консольные приложения\mathtool"
```

Для уже созданного окружения на этом компьютере:

```powershell
.\.venv\Scripts\python.exe mathtool.py --help
.\.venv\Scripts\python.exe mathtool.py solve
.\.venv\Scripts\python.exe mathtool.py solve -a 1 -b -3 -c 2
.\.venv\Scripts\python.exe mathtool.py stats --input numbers.txt
"4 1 5" | .\.venv\Scripts\python.exe mathtool.py stats
.\.venv\Scripts\python.exe mathtool.py series --func sqplus --terms 6
.\.venv\Scripts\python.exe mathtool.py series --func third --eps 0.0001
.\.venv\Scripts\python.exe mathtool.py integrate --func ratio --from 0 --to 20 --steps 1000
```

На другом компьютере после клонирования репозитория создать своё окружение:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe mathtool.py --help
```

При активном окружении можно использовать короткую команду `python`.
Без параметров выводится общая справка. Для справки отдельной команды добавить
`--help`, например `python mathtool.py series --help`.

## Команды

- `solve` принимает целые A, B, C с модулем не более 10000. Указать все три
  коэффициента или ни одного. Во втором случае программа запросит их по очереди.
  Корни выводятся с тремя знаками после запятой.
- `stats` читает числа из файла UTF-8 (`--input`) или стандартного ввода.
  Пробелы и переводы строк разделяют числа. При ручном вводе завершить поток
  сочетанием Ctrl+Z и Enter. Допускается от 1 до 20 конечных чисел с модулем
  не более 10000. Выводятся количество и 11 показателей. При одном числе
  стандартное отклонение с делителем N-1 выводится как `НЕ СУЩЕСТВУЕТ`.
- `series` поддерживает `third` и `sqplus`. Указать ровно один параметр
  `--terms` (1–10000) или `--eps` (0 < eps <= 0.0001). Сумма включает первое
  слагаемое с модулем меньше eps. Предел цикла по точности — 100000 итераций.
  Например, `third --eps 0.000001` завершится ошибкой достижения предела.
- `integrate` поддерживает `ratio` на [0, 20] и `root` на (-5, 5).
  Обязательны `--from`, `--to`, `--steps`. Пределы конечны, нижний меньше
  верхнего, шагов от 1 до 100000. Координата прямоугольника — `a + i * dx`.

Результаты печатаются в stdout, ошибки — в stderr. Коды завершения:
`0` — успех, `1` — ошибка данных или файла, `2` — ошибка командной строки argparse.
В PowerShell код последнего запуска показывает `$LASTEXITCODE`.
Порядок именованных параметров произвольный, сокращения имён запрещены.
При повторении одного параметра argparse сохраняет последнее значение.

## Устройство проекта

- `main.py` — учебная программа из первой работы.
- `mathtool.py` — точка входа, обработчики команд и весь ввод-вывод.
- `cli.py` — два этапа разбора через argparse и subparsers.
- `calc/equation.py` — проверка коэффициентов и решение уравнений.
- `calc/stats.py` — проверка последовательности, функции показателей и их таблица.
- `calc/series.py` — функции слагаемых, таблица рядов и общие циклы суммирования.
- `calc/integration.py` — функции, допустимые промежутки и цикл интегрирования.
- `calc/__init__.py` — пустой файл пакета.
- `numbers.txt` — пример 4 1 5.
- `tests.txt` — воспроизводимые проверки с полным stdout, stderr и кодом возврата.

Расчётные функции принимают аргументы и возвращают значения, без ввода-вывода.
Вычисление дисперсии проходит в два этапа для уменьшения потери точности.
В таблицах хранятся функции, поэтому добавление формулы не меняет общие циклы.

## PyCharm

Открыть каталог `mathtool`, выбрать Python проекта и его окружение `.venv`.
На этом компьютере настроены запуски:

- `mathtool help` — общая справка;
- `mathtool solve` — интерактивный ввод коэффициентов;
- `mathtool stats` — пример из numbers.txt;
- `mathtool series` — sqplus с точностью 0.0001;
- `mathtool integrate` — ratio на [0, 20], 1000 шагов.

Переключение — список запусков сверху. Зелёная кнопка запуска или Shift+F10
выполняет выбранную команду. Аргументы меняются через Edit Configurations
в поле Parameters. Настройки IDE и окружение исключены из Git и создаются
на каждом компьютере отдельно.
